# Exclusive Quiz Duck Race frames

Generated with the built-in image generation tool after inspecting the deployed factory game painted frame assets. These are new Duck Race artworks, not recoloured/copied factory frames. Three original generations: open panel, amber button, teal button. Original paths and sizes are retained in provenance.json.

Identity: carved walnut, forest-teal enamel, antique brass lips, integrated sculpted duck-foot medallions and grass details. Straight middle rails and preserved end caps support nine-slice. Normal/hover/pressed/disabled states are local image colour/light variants of the generated buttons, not independent AI generations.

SVG files embed the generated transparent WebP artwork. They are deliberately labelled raster-in-SVG, not pure vector paths. The central opening of the panel has alpha 0. Buttons have an opaque enamel face. Application CSS arranges content and performs border-image nine-slice sizing; it does not draw the frame ornament.

Reference generation prompts: panel — one premium orthographic square open-centred game UI frame, transparent centre and exterior, carved walnut outer moulding, deep forest-teal enamel, brass rounded lip, four small duck-foot medallions and curling grass at corners, straight rails, no text/no glow. Amber button — use the panel as style reference only, new single front-on horizontal button, walnut/brass border, dimensional honey-amber enamel face, duck-foot end caps, blank central 70%, transparent exterior. Teal button — matching new secondary button with forest-teal textured enamel, brass bevel, walnut border, grass and duck-foot end caps, no text.
