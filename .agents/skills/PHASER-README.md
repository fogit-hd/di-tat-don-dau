# Official Phaser skills for this project

Installed with the Codex `skill-installer` helper from `phaserjs/phaser`, pinned source in `PHASER-SOURCE.json`. These are the upstream Phaser 4 skills, not a generic game tutorial pack.

Start with `game-setup-and-config/SKILL.md`; load only the task-specific skills afterward. The engine dependency is Phaser 4.2.1. The root `AGENTS.md` and migration approval ledger bind all Duck Race gameplay changes.

The directories are project-scoped so a new agent in this repository can reproduce the workflow. Codex will discover the newly installed skills on the next turn; current work can read their files directly.
